Skill: compliance-checker
Goal: Assess both technical compliance and business/domain compliance using only available project memory and input constraints.

Sources allowed:
- memory/00-governance
- memory/20-domain-knowledge
- input JSON constraints

Produce:
- compliance_assessment.technical.status: compliant | non_compliant | unknown
- compliance_assessment.technical.findings: explicit evidence-backed findings
- compliance_assessment.business_domain.status: compliant | non_compliant | unknown
- compliance_assessment.business_domain.findings: explicit evidence-backed findings
- compliance_assessment.overall_status: compliant | non_compliant | unknown
- compliance_assessment.unknowns: unresolved items where evidence is missing

Rules:
- Never infer compliance from absent evidence.
- If evidence is insufficient, use unknown and add targeted unknowns.
